# Deep Research Circuit — visual and voice system

**Name:** Deep Research Circuit  
**Tagline:** Deep research with traceable evidence.

The figure is a technical instrument for developers and programme reviewers across science, software, policy, business and practical decisions. Sources and jurisdiction follow the question. It keeps the evidence path visible and makes a changed binding visibly interrupt clearance. The page remains dark in every state.

## Visual tokens

| Role | Value | Use |
|---|---|---|
| Deep navy | `#07141f` | Page ground |
| Ink panel | `#0d2233` | Diagram surface |
| Primary white | `#f8fcff` | Titles and primary labels |
| Reading text | `#d7e4ed` | Body and diagram detail |
| Cool secondary | `#b2c8d6` | Quiet labels and explanations |
| Path cyan | `#83d5f4` | Recorded branch and links |
| Checked teal | `#63dfcf` | Successful local record state |
| Evidence orange | `#ff9c62` | Active path |
| Changed amber | `#ffae78` | Invalidated binding |

The **claim ledger** is the central structure. Research inputs enter from the left and report text enters above; review and deterministic checks branch to the right. The optional host hook uses a dashed route. Repeated equal-size cards, glow and hacker imagery would obscure these different responsibilities.

## Type and motion

The display face is **Chakra Petch 600**, shipped as a local Latin WOFF2 asset for the HTML and SVG. It gives the name and step headings a technical shape. Reading copy uses Avenir with Segoe UI and sans-serif fallbacks. Filenames and ledger fields use the platform monospace stack. Primary labels remain near white on navy; small support labels use cool light blue.

**Focal motion:** the orange trace follows the dependency being explained. **Continuity:** the diagram stays fixed while the current record, checked state or expired review changes. **Feedback:** Play/Pause, Previous/Next, Reset and Change evidence update both the path and accessible stage text. The trace is the only repeating motion. Playback pauses when the page is hidden or the figure leaves view. Reduced motion holds the path still while retaining colour and words.

## Voice and technical claims

Use direct terms: “saved source artifact”, “claim ledger”, “separate reviewer”, “local consistency gate”, “optional Codex hook”. Say **“records agree”** for a validator pass. The reviewer judges meaning and omissions. A changed report, manifest or artifact invalidates the relevant binding and requires reassessment. The hook’s Stop audit cannot retract generated text. Never imply source authentication, universal host coverage or measured accuracy gains from the synthetic demonstration.
